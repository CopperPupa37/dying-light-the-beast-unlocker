## 🧩 About

**Dying Light The Beast catalog** is a curated list of Dying Light The Beast open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD tweaks, menu toggles
- **Quality-of-Life Helpers** — loot notes, map markers, config presets
- **Research Notes** — movement layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Movement Helpers
- Movement Notes — study parkour routes and traversal layouts
- Stamina Layout Notes — review stamina usage in single-player runs
- Grapple Aim Notes — practice grapple targeting in the sandbox
- Speed Toggle — adjust traversal speed notes for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Unlock Notes — browse cosmetic and gear catalog entries
- Custom Skin Notes — organize player cosmetics
- HUD Toggle — improved HUD visibility for review

### 🏋️ Exploration Layout
- Map Marker Notes — segment study on any district
- Loot Route Notes — chain patrol routes in the editor
- Safehouse Notes — organize safehouse layouts for study
